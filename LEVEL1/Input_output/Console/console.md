# console.log()

Prints (outputs) something to the console/terminal. This is how you see what your code is doing — the main tool for checking values.

```js
console.log("Hello world");
console.log(name);
console.log("Name:", name, "Age:", 20); // multiple values, comma separated
```

👉 Basically: `console.log()` = show me this value. Works in Node.js and in the browser.

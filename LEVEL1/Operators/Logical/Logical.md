# Logical Operators

Used to combine or flip true/false conditions.

```js
a && b  // AND - true only if BOTH are true
a || b  // OR  - true if AT LEAST ONE is true
!a      // NOT - flips true to false, or false to true
```

Example: "can enter the club if age is 18+ AND has an ID"
```js
age >= 18 && hasID
```

👉 Basically: `&&` = both, `||` = either, `!` = opposite.

# Ternary Operator

A shortcut for a simple if/else, written in one line.

```js
condition ? valueIfTrue : valueIfFalse
```

Example:
```js
let result = age >= 18 ? "Adult" : "Minor";
```

This means: "if age >= 18 is true, result = 'Adult', otherwise result = 'Minor'."

👉 Basically: `condition ? this : that` — a one-line if/else.

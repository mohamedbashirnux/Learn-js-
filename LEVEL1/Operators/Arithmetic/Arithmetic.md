# Arithmetic Operators

Used for doing math with numbers.

```js
let a = 10;
let b = 3;

a + b   // 13 - add
a - b   // 7  - subtract
a * b   // 30 - multiply
a / b   // 3.333... - divide
a % b   // 1  - remainder (what's left over after dividing)
a ** b  // 1000 - power (10 * 10 * 10)
```

👉 Basically: normal math symbols, plus `%` (remainder) and `**` (power) which are the new ones.

# What is an Operator?

An operator is a **symbol that does something with values** — math, comparing, combining, or assigning. You've actually already used some without naming them (`=` to store a value, `+` to join text).

```js
let total = 5 + 3; // + is an operator, does the adding
```

## The 5 types you're learning

1. **Arithmetic** — does math (`+ - * / %`)
2. **Assignment** — puts/updates a value in a variable (`= += -= *= /=`)
3. **Comparison** — compares two values, gives back true/false (`== === != !== > < >= <=`)
4. **Logical** — combines true/false conditions (`&& || !`)
5. **Ternary** — a shortcut one-line if/else (`? :`)

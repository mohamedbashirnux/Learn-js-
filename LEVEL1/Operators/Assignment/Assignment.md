# Assignment Operators

Used to put a value into a variable, or update it. `+=`, `-=`, etc. are just shortcuts.

```js
score = score + 5; // long way
score += 5;         // same thing, shorter

score -= 5; // score = score - 5
score *= 2; // score = score * 2
score /= 3; // score = score / 3
```

👉 Basically: `+=` `-=` `*=` `/=` are shortcuts that update the variable using its own old value.

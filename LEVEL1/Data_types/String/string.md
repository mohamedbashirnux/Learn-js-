# String

A String is just text. Always wrapped in quotes — single `' '`, double `" "`, or backticks `` ` ` ``.

```js
let name = "Amiin";
let city = 'Mogadishu';

let sentence = `My name is ${name}`; // backticks let you plug variables in with ${}

console.log(name);
console.log(city);
console.log(sentence);
```

**Output:**

```text
Amiin
Mogadishu
My name is Amiin
```

👉 Basically: String = text in quotes. `console.log()` displays the value in the console.

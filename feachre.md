

## 🔥 Features to Add

### 1. 📝 Assignment Submission

Teachers can create assignments for their classes with instructions and a deadline.

Students can view the assignment and upload their work directly through the application.

**Example:**

**Python — Assignment #2**

* 📅 Deadline: September 5
* 📋 Instructions: Complete the given exercises.
* 📎 Student uploads: `Mohamed_Assignment2.pdf`

Teachers can see who has **submitted** and who is **missing**.

---

### 2. 📢 Class Announcements

Teachers can send announcements directly to their classes instead of using WhatsApp.

**Example:**

**Python — Announcement**

> 📢 Tomorrow's lecture will start at 9:00 AM instead of 10:00 AM.

Students in the class receive the announcement and notification.

---

### 3. 💬 Class Questions & Discussion

Students can ask questions related to a subject or lesson directly through the application.

**Example:**

**Python — Chapter 4: OOP**

👨‍🎓 Student:

> Can you explain inheritance again?

👨‍🏫 Teacher:

> Sure, I will explain it during the next lecture.

Students in the same class can also see the discussion and benefit from the teacher's answers.

---

### 4. 📝 Exam Schedule

Students can view their exam schedule directly in the application.

**Example:**

**Python**

* 📅 Date: September 12
* ⏰ Time: 10:00 AM
* 📍 Hall: Hall A

Students can also receive reminders about upcoming exams.

---

### 5. 📚 Organized Course Materials

Teachers can organize their lessons and learning materials by chapters or topics.

**Example:**

# 🐍 Python

📁 **Chapter 1 — Introduction**

📁 **Chapter 2 — Variables**

📁 **Chapter 3 — Functions**

📁 **Chapter 4 — OOP**

Each chapter can contain:

* 📄 PDF
* 📊 PowerPoint
* 💻 Code
* 📝 Exercise
* 📚 Additional material

Students can open or download the materials directly from the application.

---

### 6. 📋 Student Requests

Students can submit requests to the Faculty through the application instead of always visiting the Faculty office.

**Example:**

**Attendance Correction Request**

* 👤 Student: Mohamed
* 📚 Subject: Python
* 📅 Date: August 22
* 📝 Reason: I was present but was marked absent.

Faculty can review the request and **Approve ✅ / Reject ❌** it.

---

### 7. 📅 Student Calendar

Students can have one calendar showing their classes, assignments, exams, and important academic events.

**Example:**

**Monday**

* 🕘 08:00 — Python — Hall A
* 🕙 10:00 — Database — Hall B
* 🕑 02:00 — Web Engineering — Lab 2

**Upcoming**

* 📝 Database Assignment — Due tomorrow
* 📚 Python Exam — September 15

### 12. 📝 Online Quiz System

Teachers can create quizzes for their classes directly from their portal.

A teacher can define:

* 📝 Quiz title
* 📚 Subject
* 👥 Class
* ⏰ Start time
* ⏳ End time
* 🔢 Number of questions
* 🎯 Correct answers

The quiz can support different question types such as:

**Multiple Choice**

> What is a variable in Python?

A. A function
B. A container for storing data
C. A database
D. A loop

**True / False**

> Python is a programming language.

☑ True
☐ False

When the student submits the quiz, the system automatically checks the answers and calculates the result.

**Example:**

> 🎉 Quiz Completed!
>
> 📝 Python — Chapter 3
> ✅ Correct: 8
> ❌ Wrong: 2
> 🎯 Score: **80%**

The teacher does **not** need to manually check every answer. The system automatically calculates the student's result.

The teacher can also see:

* 👥 Students who completed the quiz
* 📊 Student scores
* 📈 Class average
* 🏆 Highest scores
* 📉 Lowest scores
* ⏰ Students who missed the deadline

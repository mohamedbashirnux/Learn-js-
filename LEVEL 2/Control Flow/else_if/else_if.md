# else if Statement

## What is else if?

The `else if` statement is used when we want to check **another condition** if the first `if` condition is `false`.

It is used together with `if` and `else`.

The basic structure is:

```js
if (condition1) {
    // code to run
} else if (condition2) {
    // code to run
} else {
    // code to run
}

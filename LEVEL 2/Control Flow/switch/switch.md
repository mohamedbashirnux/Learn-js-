# switch Statement

## What is switch?

The `switch` statement is used to choose between multiple possible values.

It is useful when we want to compare **one value** with several possible cases.

The basic structure is:

```js
switch (value) {
    case value1:
        // code to run
        break;

    case value2:
        // code to run
        break;

    default:
        // code to run if no case matches
}
